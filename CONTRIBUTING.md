# Как добавить материал

Задания, теория и учебные базы лежат в каталоге `content/`. Приложение собирает их при сборке. Править TypeScript ради нового урока не нужно.

Проверка после правки: `npm test`, затем `npm run dev`. На GitHub то же самое делает workflow CI.

## База

В `content/datasets/`:

- `имя.sql` — таблицы и строки, которые видит ученик;
- `имя.hidden.sql` — другие строки для проверки. Сообщение об ошибке их не показывает, поэтому набор должен ловить решение, которое случайно подошло к видимым данным;
- запись в `index.json`: `id`, `title`, `note`, `order`.

`id` совпадает с именем файла. В обоих файлах одни и те же таблицы и столбцы.

## Тема

Папка `content/topics/NN-id/`, например `05-window`. Внутри обязателен `topic.md`:

```markdown
---
id: window
title: Окна
kicker: "05"
---

Одно предложение, о чём тема. Оно видно на главной.
```

`id` совпадает с хвостом имени папки.

## Теория и задание

Файлы в папке темы идут по имени: `00-….md`, `01-….md`. Теорию можно поставить перед заданиями и между ними. На странице темы блок теории показывается целиком, задание — ссылкой.

Теория:

```markdown
---
kind: theory
id: window-intro
title: Зачем окно
---

Текст. Абзацы разделяйте пустой строкой. `код` и **жирное** сохраняются.
```

Задание:

```markdown
---
kind: exercise
id: window-rank
title: Номер в группе
seed: shop
columns: [name, place]
orderMatters: true
level: 2
starter: |
  SELECT name
  FROM customers
solution: |
  SELECT name
  FROM customers
hints:
  - Первая подсказка, без готового запроса.
  - Вторая, уже ближе к форме ответа.
  - Третья может содержать короткий запрос.
---

## Теория

Пара предложений именно к этому заданию.

## Задание

Что показать и какие столбцы. Имена столбцов сверются без учёта регистра.

## Разбор

Почему такой запрос.
```

Имя файла задания — `NN-` плюс `id`, например `02-window-rank.md`. Подсказок ровно три. `seed` — это `id` базы. `orderMatters: true`, если проверять порядок строк. `level` — 1 (легко), 2 (средне) или 3 (сложно). `dialectNote` — необязательная строка, когда SQLite ведёт себя иначе, чем PostgreSQL.

В запрос урока проходит один `SELECT` или `WITH … SELECT`. Запись, несколько операторов и `PRAGMA` проверка отклоняет.

Решение должно возвращать заявленные столбцы и хотя бы одну строку и на видимой базе, и на скрытой. Это проверяет `npm test`.
